# Experiment results

Large outputs stay out of Git. Each run should include its ID, code commit, config, data and split hashes, model revisions, prompts, seed, dependency snapshot, hardware, metrics, per-question predictions and latency records. P6 defines the shared record schema in Week 1. Add final external results links after checking collaborator access.

Reviewed, compact final outputs are tracked in [final/](final/README.md). Temporary runs remain ignored; large input artifacts remain linked rather than duplicated.
