# 第 1 周工作报告：QASPER 数据基础

截至 $2026$ 年 $9$ 月 $26$ 日

## 工作概况

本周我完成了固定版本 QASPER 数据的获取与质检、三份官方 split 的统一导出、`Passage` 数据基础与两种语料的构建核验，并检查了固定版本数据中的图表文件和表格正文覆盖。原始数据保留在本地，派生文件可按共享说明复现。

## 已完成工作

### 固定数据与质检

我使用 `allenai/qasper` 固定修订 `fdc9d8214fbab5dd782958601db4d678e6934a54`，对应来源版本 `0.3.0`。原始 `train`、`validation`、`test` 文件及 `manifest.json` 的行数和哈希均完成核对；三个 split 分别有 $888$、$281$、$416$ 篇论文，共 $1{,}585$ 篇，检查记录显示论文 ID 在 split 间互斥。

### 统一导出与分离

我保留原始三份 split 不变，在派生层按 `train`、`validation`、`test` 的顺序物理合并记录，并在每条导出记录中保留 `source_split`，用于追溯来源和保持评估边界。

`papers.jsonl` 保留论文的 `full_text`、图表元数据及其他原始论文字段，并移除顶层 `qas`；`qa.jsonl` 每行保存一个问题及其完整答案标注和证据字段，另加 `paper_id` 与 `source_split`。两份文件通过 `paper_id` 关联。

导出共包含 $1{,}585$ 篇论文、$5{,}049$ 个问题和 $7{,}993$ 条答案标注。独立结构复核通过；我还逐项比较了所有原始论文及问题的字段投影，字段和值均一致。结构复核只用于投影、计数、哈希和论文关联检查，没有预览问题或答案内容，也没有将其用于调参。

官方 split 到项目角色的映射仍标记为 `v0-proposed`。含 `test` 论文正文的语料仅用于推理索引；`test` 问题、答案和证据标注不用于开发调参。

### 段落模式及语料

我定义并验证了八字段 `Passage`：`passage_id`、`paper_id`、`title`、`section`、`chunk_number`、`text`、`previous_passage_id` 和 `next_passage_id`。构建器只读取论文 `full_text`，在原始章节边界内分块，以稳定 ID 标识段落，并仅连接同一章节内相邻的段落。当前工作配置为每块 $200$ 词、重叠 $40$ 词；这组参数不代表实验最优值或永久冻结的设置。

### 图表与表格核验

我核验了固定修订的全部 $1{,}585$ 篇论文：$1{,}551$ 篇含图表记录，共 $11{,}364$ 条引用，其中表格 $6{,}492$ 条、图片 $4{,}872$ 条。`figures_and_tables` 记录包含 caption 和 `.png` 文件名；固定版本官方归档没有相应图像文件，本地可定位图像为 $0/11{,}364$。

`full_text` 偶尔会复述表格中的个别事实，但不含可依赖的完整表格单元格数据。定向抽样发现，有些表格事实也出现在正文，另一些答案只由缺失图像中的表格证据支持；这些样本不能用于推算总体问答覆盖率。

### 交付成果与复现依据

共享说明 [`data/README.md`](../../data/README.md) 记录固定版本下载、导出与独立复核、`Passage` 样本及两种语料的复现入口。原始数据与生成的 JSONL、manifest 保持在 Git 忽略目录中，队友可按说明在本地生成。

本次工作交付了 `papers.jsonl`、`qa.jsonl` 及 `qasper_export.manifest.json` 所定义的统一导出流程，以及 `development` 语料、全论文正文推理索引和 $100$ 条复现样本对应的构建与复核结果。以上清单和报告中的 SHA-256 值用于核对固定输入及派生结果。

## 当前限制

固定版本数据提供图表 caption 与文件名引用，但不提供相应图像文件；正文也不保证包含完整表格内容。因此，部分依赖图表的问答证据无法从当前 `full_text` passage 中恢复，实际整体覆盖率尚不能由定向抽样确定。
