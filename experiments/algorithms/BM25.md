# BM25：如何从论文中找出与问题相关的分块

本次分块大小实验已选择 `bm25`。本文先讲直觉，再讲当前 P3 代码的输入、输出和完整流程。英文版见 [BM25.en.md](BM25.en.md)。

## 1. 核心思路

BM25 是一种按词匹配的检索算法：把问题和候选分块拆成词，给每个分块打分，再把分数较高的分块排在前面。它不需要训练模型或下载模型权重，也不负责生成答案。

可以把它理解为给关键词匹配打分，主要考虑三件事：

1. **这个词是否有区分度**：如果一个问题词只在少数分块中出现，通常更能帮助找到相关内容；如果几乎每个分块都有这个词，它的区分度就低。
2. **这个词在分块中出现几次**：在权重为正时，出现多次通常比只出现一次得分高，但增益逐渐变小。重复出现 $10$ 次，不会简单地得到出现 $1$ 次的 $10$ 倍分数。
3. **分块有多长**：长分块本来就更容易包含问题词，所以算法会按长度调整得分，减少长分块仅靠文字多占便宜的情况。它不是无条件偏好最短的分块。

例如，问题包含 `dropout` 和 `overfitting`。讨论这两个词的分块通常会排得较高。但只写了意思相近的 `randomly disabling neurons` 的分块，可能因为没有相同词而被漏掉。BM25 主要依靠词面匹配，不能保证理解同义表达、否定关系或答案是否正确。

## 2. 输入是什么

这里把每个 chunk 当作一篇待检索的“小文档”。代码有建索引和查问题两个阶段，输入也分成两类。

| 阶段 | 输入 | 在本实验中是什么 |
| --- | --- | --- |
| 建索引 | 候选分块集合 | 从 `data/processed/papers.jsonl` 经分块器得到的记录；主要用 `paper_id` 分组、用 `text` 统计词、用 `passage_id` 标识结果。 |
| 查问题 | `query` | 从 `data/processed/qa.jsonl` 选出的一个问题的原始文字。 |
| 查问题 | `paper_id` | 问题所属论文的 ID；只搜索这篇论文的分块。 |
| 查问题 | `top_k` | 最多返回多少个分块；本实验固定为 $5$。 |

论文标题、章节名和相邻分块 ID 会随记录保留，但当前 BM25 只对 `text` 字段评分，不单独给标题或章节加权。答案和人工标注证据不参与 BM25 建索引或打分；评估程序另外使用它们筛选可评估问题、核对检索结果。

## 3. 输出是什么

输出是按分数从高到低排列的分块列表。每条结果包含原分块记录、原始 BM25 分数 `score` 和从 $1$ 开始的名次 `rank`。P3 适配层把它转换成有序的 `(passage_id, score)` 列表，评估程序再按 ID 找回完整文本和原文位置。

这个分数表示当前问题下的排序依据，不是“回答正确的概率”。例如，得分 $2$ 不代表相关概率为 $2\%$ 或 $100\%$。不同问题、论文或分块大小的原始分数也不宜直接比较。

当前实现不设置最低分门槛，零分或负分的分块也会参与排序。可用分块不足 $5$ 个时返回全部；论文 ID 不存在时返回空列表。同分时按 `passage_id` 升序排列，因此所有分块都是零分时，也可能返回 $5$ 个分块，但这不表示找到了相关证据。

## 4. 完整流程

```text
准备阶段：对每种分块大小分别执行
论文正文 → 分块 → 按 paper_id 分组 → 拆词 → 统计词频、长度和词的分布 → 建好索引

查询阶段：对每个问题执行
问题文字 + paper_id + top_k
    → 选中该论文的索引
    → 对问题拆词
    → 为该论文的每个分块计算 BM25 分数
    → 按分数降序、分块 ID 升序排列
    → 返回最多 top_k 个分块

评估阶段：由 P3 评估程序执行
返回的分块 ID → 找回完整分块 → 与人工标注证据比较 → 计算证据指标和检索词数
```

### 第一步：准备分块

对同一批论文分别生成约 $150$、$200$、$250$ words 的候选语料，固定重叠 $40$ words。每种大小独立建索引，每篇论文也有自己的索引。BM25 不负责决定分块边界；它接收已经切好的分块。

### 第二步：把文字拆成词

问题和分块都先调用 `casefold()` 统一大小写，再使用 `re.findall(r"\w+", text.casefold())` 提取连续的 Unicode 字母、数字和下划线等词字符。例如，`Dropout reduces overfitting.` 得到 `dropout`、`reduces`、`overfitting`。

当前实现不去除 `the`、`is` 等常见词，不把 `models` 和 `model` 合并，也不做同义词替换。问题中的重复词不会去重，会重复参与求和。

分块大小与报告词数采用另一种计数方式：以空格、换行、制表符等空白字符为分隔，每段连续的非空白文字算一个 word，不继续拆开其中的标点。分块器用 `\S+` 找到这些片段；报告用 `len(text.split())` 统计 chunk 或原文 paragraph 的词数，检索总词数则是返回的各个 chunk 的词数之和。实验中的 $150/200/250$ words 分块大小和 $40$ words 重叠也采用这种单位。

例如，同一段文字 `A state-of-the-art model.` 按空白分成 `A`、`state-of-the-art`、`model.`，报告词数为 $3$；BM25 则拆成 `a`、`state`、`of`、`the`、`art`、`model`，评分公式中的分块长度为 $6$。两者衡量的是同一段文字的长度，只是计数单位不同，分块文本和边界并没有改变。paragraph 是原文段落，chunk 是分块器生成的检索单元，两者不一定一一对应。

### 第三步：统计当前论文的分块

需要记录每个分块有多少个词、每个词在该分块中出现几次、每个词出现在多少个分块中，以及这篇论文所有分块的平均长度。

注意，“多少个分块”与“出现多少次”不同：某个词在同一个分块中出现 $10$ 次，仍只算出现在 $1$ 个分块中。当前代码按论文统计这些量，不使用所有论文合在一起的词频。

### 第四步：给每个分块打分

对问题中的每个词，计算它对当前分块的贡献：先看这个词的区分度，再结合它在分块中的出现次数和分块长度。把所有问题词的贡献相加，得到这个分块的总分。在当前论文索引中不存在的问题词贡献为零。

### 第五步：排序并返回

给该论文的所有分块打完分，按总分从高到低排序，同分按分块 ID 升序排列，取前 $5$ 个。当前代码直接为所有候选分块计算分数，没有先筛掉不含问题词的分块。

### 第六步：检查是否找到了证据

P3 评估程序将返回分块映射回原文，检查是否覆盖人工标注证据，并统计返回文字量。BM25 自己不知道标准答案在哪里；“词匹配得分高”和“完整找到回答所需证据”是两件需要分别检验的事。

## 5. 一个可以手算的例子

假设一篇论文只有以下 $5$ 个分块，每块拆词后长度都是 $4$。查询文字为 `dropout overfitting`，仍使用实验中的 `top_k=5`。

| 分块 ID | 分块文字 | 匹配查询词 |
| --- | --- | --- |
| `A` | `dropout reduces model overfitting` | `dropout`、`overfitting` |
| `B` | `regularization improves model generalization` | 无 |
| `C` | `experiments compare training settings` | 无 |
| `D` | `results show better accuracy` | 无 |
| `E` | `models use attention layers` | 无 |

`dropout` 和 `overfitting` 各只出现在 $1$ 个分块中，各自的词权重为 $\ln((5-1+0.5)/(1+0.5))=\ln 3\approx1.099$。在 `A` 中，每个查询词都出现 $1$ 次，分块长度又等于平均长度，因此下面公式中的词频与长度因子恰好为 $1$。

所以 `A` 得分约为 $1.099+1.099=2.197$，其余分块均为 $0$。返回顺序是 `A`、`B`、`C`、`D`、`E`。只有 `A` 有词面匹配，后面四项只是因为当前设置允许返回零分结果。这个例子用于解释算法，不是实际实验结果。

## 6. 公式与当前固定实现

读到这里已经能理解检索流程。若要对照代码，单个分块的分数写为：

$$
\operatorname{score}(q,d)=\sum_{t\in q}w(t)\frac{f(t,d)(k_1+1)}{f(t,d)+k_1\left(1-b+b\frac{|d|}{\operatorname{avgdl}}\right)}
$$

| 符号 | 直白解释 |
| --- | --- |
| $q,d,t$ | 问题、一个候选分块、问题中的一个词；按问题词序列求和，重复词也重复计算。 |
| $f(t,d)$ | 这个词在当前分块中出现的次数。 |
| $\lvert d\rvert,\operatorname{avgdl}$ | 当前分块拆词后的长度、当前论文所有分块的平均长度。 |
| $w(t)$ | 这个词的权重，也叫逆文档频率（IDF）；这里的“文档”指分块。 |
| $k_1$ | 控制重复出现的词还能增加多少得分；当前为 $1.5$。 |
| $b$ | 控制长度调整的强度；$0$ 表示不按长度调整，$1$ 表示完全按长度比例调整，当前为 $0.75$。 |

本项目调用 `rank_bm25.BM25Okapi`。该库先计算 $\operatorname{IDF}_{raw}(t)=\ln\frac{N-n(t)+0.5}{n(t)+0.5}$，其中 $N$ 是当前论文的分块数，$n(t)$ 是包含该词的分块数。若原始 IDF 为负，则用 $\epsilon\times\overline{\operatorname{IDF}_{raw}}$ 替换，平均值取当前论文索引全部不同词的原始 IDF，当前 $\epsilon=0.25$。这与某些教材使用始终为正的 IDF 公式不同；若这个平均值为负，替换后的权重仍可能为负，所以当前实现允许负分。若整篇论文拆词后词表为空，项目代码直接令所有分块得分为零。

| 本实验设置 | 当前值或行为 |
| --- | --- |
| 检索模式 | `retrieval.mode = "bm25"`，本次已选用。 |
| 返回数量 | `top_k = 5`。 |
| 算法参数 | 库缺省值：$k_1=1.5$、$b=0.75$、$\epsilon=0.25$；当前实验 JSON 不提供修改这三个值的入口。 |
| 检索范围 | 问题所属论文；每种分块大小、每篇论文独立统计。 |
| 参与评分的文字 | 分块 `text`；不额外拼接标题或章节名。 |
| 同分处理 | 按 `passage_id` 升序。 |
| 模型与重排 | 无模型权重、无 dense 检索、无 RRF 融合、无重排。 |

正式比较中固定检索模式和参数，只改变分块大小。分块大小变化会自然改变词频、平均长度和词权重，这属于分块变化对 BM25 的影响；不要因为不同大小的原始分数变高，就判断检索效果更好。最终仍看同一批问题上的证据覆盖、检索词数及人工可读性评审。

### 如何理解公式中的分数项

公式中乘在 $w(t)$ 后面的分数，是一个“词频与长度因子”：把某个词在分块中的出现次数，转换为经过长度调整的匹配强度。它体现两点：重复出现有帮助，但收益递减；长分块更容易包含关键词，因此要按长度调整。下面用 $F$ 表示这个因子，用 $f$ 简写 $f(t,d)$。

**先看平均长度的分块。** 当 $|d|=\operatorname{avgdl}$ 时，长度项 $1-b+b|d|/\operatorname{avgdl}=1$。代入当前的 $k_1=1.5$，分数简化为：

$$
F(f)=\frac{f(k_1+1)}{f+k_1}=\frac{2.5f}{f+1.5}
$$

| 词在分块中出现的次数 $f$ | 词频与长度因子 $F(f)$ |
| --- | --- |
| $0$ | $0$ |
| $1$ | $1$ |
| $2$ | 约 $1.43$ |
| $5$ | 约 $1.92$ |
| $10$ | 约 $2.17$ |

因此，出现 $10$ 次的因子只是出现 $1$ 次的约 $2.17$ 倍。原因是 $f$ 同时出现在分子和分母中：次数增加时，两者一起变大，重复出现带来的增益逐渐减小。在分块长度固定时，随着 $f$ 增大，因子趋近 $k_1+1=2.5$，不会无限增长。

分子中的 $(k_1+1)$ 还提供了一个方便的基准：平均长度的分块中，一个词出现 $1$ 次时，因子恰好为 $1$，因此该词对总分的贡献就是 $w(t)$。

**再看长度如何改变分母。** 把长度调整部分记为 $L$，代入当前的 $b=0.75$：

$$
L=1-b+b\frac{|d|}{\operatorname{avgdl}}=0.25+0.75\frac{|d|}{\operatorname{avgdl}},\qquad F(f,L)=\frac{2.5f}{f+1.5L}
$$

假设关键词都只出现 $1$ 次，即 $f=1$：

| 分块长度 | 长度项 $L$ | 因子 $F(1,L)$ |
| --- | --- | --- |
| 平均长度的一半 | $0.625$ | 约 $1.29$ |
| 等于平均长度 | $1$ | $1$ |
| 平均长度的两倍 | $1.75$ | 约 $0.69$ |

同样只出现 $1$ 次，关键词出现在短分块中，通常更能体现内容集中。因此，长分块对应较大的 $L$ 和分母，因子更小。这里比较的是词频相同的情况；实际排序还取决于其他问题词及其权重，不能据此断定短分块总是排在前面。这里的长度按 BM25 拆词后的词数计算，不是实验报告采用的空白分词词数。

**最后放回总分公式。** 每个问题词的贡献等于“词的区分度 $w(t)$”乘以“词频与长度因子 $F(f,L)$”，再把所有问题词的贡献相加。例如，某个词的权重为 $2$，在平均长度的分块中出现 $2$ 次，其贡献约为 $2\times1.43=2.86$。

上述“因子越大，得分越高”的直觉适用于 $w(t)>0$。当前实现可能产生负权重，此时因子越大，该词的贡献会越负；若权重为零，该词的贡献始终为零。
