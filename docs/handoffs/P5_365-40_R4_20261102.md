## 4. What changed in this branch

- `scripts/cluster/80_demo_server.sbatch` now defaults `PAPERGAP_CORPUS`,
  `PAPERGAP_DENSE_INDEX`, `PAPERGAP_BM25_INDEX`, `PAPERS_FROM` and
  `PASSAGES_FROM` to the **365/40** paths. Overriding `PAPERGAP_CORPUS`
  switches corpora, and `PAPERS_FROM`/`PASSAGES_FROM` follow it — this fixes
  a mismatch found in job 50172, where retrieval used 365/40 while
  `/passages` still served the 200/40 text (`papers=1168`).
- `scripts/check_p1_retrieval.py` added: the P5-side load check used for both
  P1 packages.
- `src/generation/server.py` already carried the `--record-fn` hook from
  `c9e2756`; this branch also merges `origin/main` (P4's factory now reads
  `PAPERGAP_*`, PR #25; gold-mapping commit `c232edb`).
